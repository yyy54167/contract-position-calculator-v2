# 仓位计算器 · 第二版

独立于 [第一版](https://github.com/yyy54167/contract-position-manager) 的页面重构副本。重写页面结构、视觉样式与交互层，原样保留 `calc.mjs` 计算模块。基于第一版提交 `64586c85433cee01ae7f256e6c39046e7509bd4a`；原计算模块 Git blob 为 `f73e69357ed138b6e264d6dafc39bd76d97be13e`。

## 使用体验

- 账户与风险、入场与止损分组输入，实时呈现保证金和计划止损金额。
- 自动判定多空方向，价格关系图核对开仓价与止损价。
- 资金占用环、仓位明细、完整方案复制、恢复默认。
- 手机端页内结果入口、iOS 安全区域、系统明暗模式、离线 PWA。
- 无服务器与第三方请求；输入只保存在当前设备，新版使用独立存储键。

默认：全仓仓位 100 USDT、风险 5%、杠杆 10 倍、开仓价和止损价为空。

## 计算逻辑

止损金额 = 全仓仓位 × 风险百分比 ÷ 100

止损距离比 = |开仓价 − 止损价| ÷ 开仓价

保证金（仓量）= 止损金额 ÷（止损距离比 × 杠杆）

名义仓位 = 保证金 × 杠杆；合约数量 = 名义仓位 ÷ 开仓价。

止损价低于开仓价判定做多，高于则判定做空。未计手续费、滑点、资金费率、强平规则及下单精度。

## 文件结构

- `calc.mjs`：原版计算模块，保持不变。
- `app.js`：输入、显示、价格关系、复制、本地保存。
- `format.mjs`：数字显示，不参与计算。
- `styles.css`、`index.html`：新版视觉与页面。
- `sw.js`、`manifest.webmanifest`：离线与主屏幕支持。
- `tests/`：原有计算测试。
